# Philippine Population Analytics

A responsive web dashboard based on `Population (1).ipynb`.

## Features

- Interactive regional and year filters
- Population trend, ranking, growth, and distribution charts
- Regional profile cards
- Machine-learning model results
- Upload support for `.xlsx`, `.xls`, and `.csv` files
- CSV export

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

The app automatically loads `population_philippines_annual_2000_2025.xlsx` when hosted in this repository.
